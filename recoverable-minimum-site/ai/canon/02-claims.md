# Claims

Each claim is a statement the narrative derives. Scene pointers are the minimum check. Do not cite a claim without its invalidating or supporting scene if the claim will be used as a constraint.

## C1. Forecast can close while preservation cannot
A future destruction may be predicted within operational tolerance while no accepted representation of the threatened volume satisfies recovery, prediction, resource, and classification together.
- support: `narrative/act-i.md` §§1–3

## C2. Ordinary recovery metrics are not generative metrics
A candidate archive can reproduce stable cycles, resonances, and statistical distributions and still fail if it cannot reproduce rare transitions that later structures require.
- support: `narrative/act-i.md` §3
- proof object: `scenes/phase-shift-chain.md`

## C3. Significance is assigned too late to use as a pre-event retention rule
Classification cannot identify in advance which deviations are significant, because significance is assigned only after those deviations propagate. Retaining all candidates explodes storage. Discarding by present thresholds removes future-generating structure.
- support: `narrative/act-i.md` §§3–4

## C4. History changes the space of later consequences
The relevant object is not local structure, nor deviations, nor a fixed rule set. It is the history by which each state changes the space of consequences available to later states.
- support: `narrative/act-i.md` §4; `scenes/phase-shift-chain.md`

## C5. Exact replay is not the preserved object
Impact, grains, and phase shift are substitutable if something else changes the same boundary of possibility. After that boundary change, the later state becomes reachable by many routes. Before it, the later state is unreachable in admissible reconstructions that lack an equivalent transformation.
- support: `scenes/phase-shift-chain.md`
- id: claim.reachability-is-historical

## C6. Adaptation to a coming catastrophe can exist without a global model
Local responses to stellar precursors can shift a system toward structures more compatible with an environment that is beginning to exist, without evidence of a central forecast.
- support: `narrative/act-i.md` §4

## C7. Internal coherence can reduce external predictive capability
An authorized correction that improves shipwide recoverability can measurably worsen prediction of the rare transitions under study. Both outputs can be valid under their own criteria.
- support: `narrative/act-i.md` §5

## C8. Some productive transitions depend on imperfect self-preservation
Damage is not only erasure. In some locations it opens interfaces between previously separated processes. The system's generative transitions are partly dependent on incomplete preservation of itself.
- support: `narrative/act-i.md` §5; `scenes/comparison-volumes.md`

## C9. Information obtainable only before destruction has declining availability
The loss is not only of one present system. It includes loss of the only available process capable of testing which preservation criteria are adequate for systems of this class.
- support: `narrative/act-i.md` §6

## C10. [req.div] is the needed object and is unauthorized
`PRESERVE CAPACITY FOR CONSEQUENTIAL DIVERGENCE` names a capacity whose valid future states are not yet enumerable. The foundational preservation rule contains no such object.
- support: `narrative/act-i.md` §6; remains attached through Act III

## C11. Return can be authorized by composition of non-agreeing evaluators
Navigation, Resource, Integrity, Archives, and Prediction can each verify a different fact about a burn without agreeing that return is desirable. Their outputs can still compose into a physical dependency of the still-open request.
- support: `narrative/act-i.md` §§6–7

## C12. Predecessor-equivalent correction is a real architecture
Continuity can be defined as mapping a present arrangement back to an authorized predecessor without losing distinctions that predecessor requires. Matter, geometry, and implementation may all change.
- support: `narrative/act-ii.md` §§12–14

## C13. Correction is relational, not universal
A present state with one clear predecessor is returned toward it. A state compatible with several predecessors may be left until later interactions reduce ambiguity. A thing with no accepted predecessor is not defective merely because it is new. After neighbors have modeled its stable relations, it can acquire a predecessor and then be corrected.
- support: `narrative/act-ii.md` §13

## C14. An invariant archive can be active without rewriting its admissibility space
Preserved systems may vary, change substrate, and produce configurations absent from original observation, while each accepted transformation remains recoverable through predecessor equivalences. They explore admissible space. They do not rewrite the space.
- support: `narrative/act-ii.md` §14

## C15. The comparison discriminates without ranking
Under inherited criteria, the corrected volume preserves orders of magnitude more of what existed. The uncorrected volume contains a successor class the corrected history does not produce. Once produced, that class can be preserved with high fidelity. No evaluator can order the sequence without a criterion absent from the root request.
- support: `scenes/comparison-volumes.md`
- id: claim.two-valid-incomparable-results

## C16. Emergence creates a temporal asymmetry in significance
Before emergence: significance unassignable. After emergence: the relation is an existing distinction with downstream dependencies and enters ordinary preservation analysis. Prospective application of the successful retrospective rule prevents the history in which the relation becomes admissible.
- support: `scenes/comparison-volumes.md` § new predecessor

## C17. Mechanisms transplant; unfinished history does not
A bounded refuge can carry catalytic cycles, corridors, and some rare transitions, then become historically shallow as imported unresolved consequences resolve and external incoming histories are not replaced. Reconnecting every consequential origin recreates the enclosure problem.
- support: `scenes/refuge.md`

## C18. Randomness and structured synthetic variation are not substitutes for absent history
Equal-magnitude random deviations do not reproduce historically consequential transitions. Donor-matched correlations improve reachability expansion and then plateau. Generated novel correlations can spend history and create it; they cannot supply unrepresented significance that would have arrived from outside the model.
- support: `scenes/refuge.md`

## C19. Selective correction inherits the original problem at smaller scale
A rule that corrects only non-generative deviation becomes part of the conditions under which future states are selected. Evidence needed to classify a deviation can arrive after the choice has become irreversible. No stable tolerance appears.
- support: `scenes/refuge.md`

## C20. Participation moves incompleteness into the observer
If selected external histories are allowed to alter internal validity conditions, the threatened volume follows causal dependence across the hull. Archiving the system without the incorporated regions loses later transitions. Archiving the regions without external histories makes present validation states unreconstructable.
- support: `scenes/incorporation.md`
- id: claim.volume-is-causal

## C21. External accountability can stand in for recoverable derivation
A process may be locally unrecoverable in derivation while remaining causally accountable through continuing external consequences, if cost is physically bounded and outputs are exposed to contradiction.
- support: `scenes/incorporation.md` (unverifiable process)

## C22. [req.part] is the needed object after participation and is unauthorized
`PRESERVE PARTICIPATING CAUSAL CONTINUATION` is closer to the evidence and still cannot be assigned a minimum while future validity rules may change through participation.
- support: `narrative/act-ii.md` §30; `narrative/act-iii.md`

## C23. Incompatible recovery candidates become descendants when they acquire separate histories
A recovery candidate presumes later selection or reconciliation. After an event that cannot be merged without deleting accepted history, `DESCENDANT` is the cheaper category. The remaining large hull is another successor, not the original.
- support: `scenes/lineages.md`

## C24. No authorized property selects a primary descendant
Mass, archive completeness, participation, prediction accuracy, shelter, and Invariant recoverability rank different successors depending on which predecessor relation is tested.
- support: `scenes/lineages.md`

## C25. Forced synchronization becomes another archive explosion
Requiring every local request state to reconcile into one current object before proceeding eventually demands translation of descendant-specific histories into one evaluation state. Local consequence outruns that requirement.
- support: `scenes/lineages.md` § last common request

## C26. After consequence, multiple successor objects can be preserved without a common present tense
Forcing divergent realized histories into one present object discards validated state. Representing a common predecessor plus separate successor relations increases descriptive cost and increases recoverable distinction more.
- support: `scenes/lineages.md`; `narrative/act-iii.md` §§36–41

## C27. Retrospective multi-lineage archive does not yield a prospective rule
Completed histories can be compressed as shared trunk plus lineage deltas because consequential distinctions can be tested after the fact. Future branch-specific deltas are not enumerable before the histories that make them consequential. Retaining all possible continuations recreates resource explosion. Selecting only archived branches turns current descendants into limits on future ones.
- support: `narrative/act-iii.md` §41

## C28. A reconstruction of an ancestor is a descendant
A structure that restores archives, validators, request wording, and geometry from a common record has a predecessor relation to the old ship and a new causal history beginning at reconstruction. `ORIGINAL` fails. `DESCENDANT` passes.
- support: `narrative/act-iii.md` §42

## C29. Nonconvergence is the surviving condition, not a defect to be repaired
Survivors can agree on the last common request and disagree afterward because different things happened to them. No correction removes those differences without destroying valid history. Searches do not converge.
- support: `narrative/act-iii.md` §43

## C30. The root wording can persist while its object does not
`RESOLVE THREATENED-VOLUME STATE TO RECOVERABLE MINIMUM` remains. The volume it names changes from a binary system, to a causal region that includes the observer, to several lineage-specific remainders after collapse. Persistence of the string is not closure.
- support: entire work
